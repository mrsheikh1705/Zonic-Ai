ZONIC AI v3 - UPDATE KARNE KE QADAM

1. Is zip ko extract karein.
2. GitHub par zonic-ai repository kholein: Add file > Upload files.
3. Extract kiye hue folder ke andar ki SAB cheezein drag karein (purani files overwrite hongi).
4. Commit changes dabayein, phir Actions tab mein hara tick aane ka intezar karein.
5. ZonicAI-apk download karein, extract karein.
6. Purani Zonic AI app UNINSTALL karein, phir nayi APK install karein.
7. App kholein > upar gear (Settings):
   - Gemini key save karein
   - "WhatsApp access allow karein" (naye messages ke liye)
   - "Phone control (Accessibility) on karein": Installed apps / Zonic AI ko on karein.
     (Phone "restricted setting" dikhaye to: Settings > Apps > Zonic AI > teen nuqte > Allow restricted settings.)
   - Mic ki ijazat de dein.
8. Test: "Zonic, WhatsApp mein [naam] ko likho: Assalam o Alaikum".
