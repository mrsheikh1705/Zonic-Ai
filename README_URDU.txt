ZONIC AI - APK banane ke qadam (computer ya phone ke browser se)

1. github.com par free account banayein.
2. New repository banayein (naam: zonic-ai, Public ya Private).
3. "uploading an existing file" par click karein.
4. Is zip ko extract karein, phir andar ke SAB files aur folders
   (.github, app, build.gradle.kts, settings.gradle.kts, gradle.properties)
   drag karke upload karein. Commit changes dabayein.
5. Upar "Actions" tab kholein. "Build APK" chalega (5 se 10 minute).
6. Khatam hone par us run ko kholein, neeche "ZonicAI-apk" download karein.
7. Zip extract karke app-debug.apk phone mein install karein.
8. App kholein, Gemini key save karein, "WhatsApp access" mein Zonic AI ko allow karein.

Agar build fail ho jaye to Actions ka laal (red) run kholein, error ka text copy karke
mujhe bhej dein, main theek kar dunga.
